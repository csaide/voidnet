# HTTP 1.0 + 1.1 Server Support Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add HTTP/1.0 and HTTP/1.1 server support to the existing `src/net/http/` module, preserving zero-copy design and the existing HTTP/0.9 path.

**Architecture:** Shared parsing functions (`codec/parse.rs`) handle the common HTTP/1.x wire format (request line, headers). Version-specific codecs (`v1_0.rs`, `v1_1.rs`) compose these and add version-specific validation. The session state machine, handler trait, and ResponseWriter all expand to support headers, body reading, keep-alive, and chunked encoding.

**Key design decisions:**
- **Offset handling:** `parse_headers` returns offsets local to the buffer slice it receives (0-based). The codec uses these local offsets with the same buffer for internal lookups (`find_content_length`, `has_header`). Only when constructing the final `Request` does the codec absolutize offsets by adding `buf_offset + req_line.consumed`. This prevents offset/buffer mismatch bugs.
- **Body reading:** `ResponseWriter` embeds body reading via a `body()` method. The handler calls `res.body().read_all(...)` first (sequential access), drops the `BodyReader`, then writes the response. This avoids borrow-splitting issues.
- **Keep-alive decision:** Instead of cloning the request buffer, the session stores an extracted `ConnectionDirective` enum (KeepAlive, Close, None) during decode. Zero-copy friendly.

**Tech Stack:** Rust, async (custom runtime via `crate::rt`), `TcpStream`/`TcpListener` from `crate::net::socket`.

**Spec:** `docs/superpowers/specs/2026-03-13-http-1.0-1.1-design.md`

**Testing:** All tests run with plain `cargo test` (no feature flags). Tests require root (configured via `.cargo/config.toml`).

```rust
/// An HTTP request with offset-based zero-copy path and header access.
///
/// Path and headers are resolved via offset lookup into the connection's
/// read buffer.
#[derive(Debug, Clone)]
pub struct Request {
    pub method: Method,
    path_start: usize,
    path_end: usize,
    pub version: Version,
    pub headers: Vec<HeaderOffset>,
    pub body_framing: BodyFraming,
}

impl Request {
    /// Create a new request with the given fields.
    pub(crate) fn new(
        method: Method,
        path_start: usize,
        path_end: usize,
        version: Version,
        headers: Vec<HeaderOffset>,
        body_framing: BodyFraming,
    ) -> Self {
        Self {
            method,
            path_start,
            path_end,
            version,
            headers,
            body_framing,
        }
    }

    /// Resolve the request path from a byte buffer.
    pub(crate) fn path_from_buf<'a>(&self, buf: &'a [u8]) -> &'a [u8] {
        &buf[self.path_start..self.path_end]
    }

    /// Returns the byte offset where the path starts in the read buffer.
    pub fn path_start(&self) -> usize {
        self.path_start
    }

    /// Returns the byte offset where the path ends in the read buffer.
    pub fn path_end(&self) -> usize {
        self.path_end
    }

    /// Case-insensitive header value lookup by name.
    ///
    /// `buf` must be the connection's read buffer that contains the header bytes.
    pub fn header_value<'a>(&self, buf: &'a [u8], name: &str) -> Option<&'a [u8]> {
        let name_bytes = name.as_bytes();
        for h in &self.headers {
            let header_name = &buf[h.name_start..h.name_end];
            if header_name.len() == name_bytes.len()
                && header_name
                    .iter()
                    .zip(name_bytes.iter())
                    .all(|(a, b)| a.to_ascii_lowercase() == b.to_ascii_lowercase())
            {
                return Some(&buf[h.value_start..h.value_end]);
            }
        }
        None
    }
}
```

```rust
/// Result of parsing a request line.
pub struct RequestLine {
    pub method: Method,
    pub path_start: usize,
    pub path_end: usize,
    pub version: Version,
    pub consumed: usize,
}

/// Parse an HTTP/1.x request line: `METHOD /path HTTP/1.x\r\n`
///
/// Returns `None` if incomplete (no \r\n found yet).
/// Returns `Some(Err)` on parse error.
/// Returns `Some(Ok)` on success with absolute offsets.
pub fn parse_request_line(buf: &[u8], buf_offset: usize) -> Option<Result<RequestLine, ParseError>> {
    let newline_pos = memchr_newline(buf)?;

    let line_end = if newline_pos > 0 && buf[newline_pos - 1] == b'\r' {
        newline_pos - 1
    } else {
        newline_pos
    };

    let line = &buf[..line_end];
    let consumed = newline_pos + 1;

    if line.is_empty() {
        return Some(Err(ParseError::InvalidRequestLine));
    }

    // Split into parts: METHOD SP path SP version
    let first_space = match line.iter().position(|&b| b == b' ') {
        Some(pos) => pos,
        None => return Some(Err(ParseError::InvalidRequestLine)),
    };

    let method_bytes = &line[..first_space];
    let rest = &line[first_space + 1..];

    // Find the second space (separating path from version)
    let second_space = match rest.iter().rposition(|&b| b == b' ') {
        Some(pos) => pos,
        None => return Some(Err(ParseError::InvalidRequestLine)),
    };

    let path = &rest[..second_space];
    let version_bytes = &rest[second_space + 1..];

    if path.is_empty() {
        return Some(Err(ParseError::InvalidRequestLine));
    }

    let method = match parse_method(method_bytes) {
        Ok(m) => m,
        Err(e) => return Some(Err(e)),
    };

    let version = match version_bytes {
        b"HTTP/1.0" => Version::Http10,
        b"HTTP/1.1" => Version::Http11,
        _ => return Some(Err(ParseError::UnsupportedVersion)),
    };

    let path_start = buf_offset + first_space + 1;
    let path_end = buf_offset + first_space + 1 + second_space;

    Some(Ok(RequestLine {
        method,
        path_start,
        path_end,
        version,
        consumed,
    }))
}

/// Find the position of the first `\n` byte in `buf`.
#[inline]
fn memchr_newline(buf: &[u8]) -> Option<usize> {
    buf.iter().position(|&b| b == b'\n')
}
```

```rust
/// Maximum number of headers allowed per request.
pub const MAX_HEADERS: usize = 64;

/// Parse HTTP headers from `buf`.
///
/// Returns `None` if the buffer doesn't contain a complete header block
/// (no terminating empty line `\r\n\r\n`).
/// Returns `Some(Err)` for malformed headers.
/// Returns `Some(Ok((headers, consumed)))` on success.
///
/// Header offsets are **local** (0-based into `buf`). The caller must
/// add the appropriate base offset when constructing the final Request.
pub fn parse_headers(buf: &[u8]) -> Option<Result<(Vec<HeaderOffset>, usize), ParseError>> {
    let mut headers = Vec::new();
    let mut pos = 0;

    loop {
        // Find end of this line
        let remaining = &buf[pos..];
        let newline_pos = match memchr_newline(remaining) {
            Some(p) => p,
            // No newline found — incomplete
            None => return None,
        };

        let line_end = if newline_pos > 0 && remaining[newline_pos - 1] == b'\r' {
            newline_pos - 1
        } else {
            newline_pos
        };

        let line = &remaining[..line_end];

        // Empty line = end of headers
        if line.is_empty() {
            let consumed = pos + newline_pos + 1;
            return Some(Ok((headers, consumed)));
        }

        if headers.len() >= MAX_HEADERS {
            return Some(Err(ParseError::TooManyHeaders));
        }

        // Find colon separator
        let colon_pos = match line.iter().position(|&b| b == b':') {
            Some(p) => p,
            None => return Some(Err(ParseError::InvalidHeader)),
        };

        let name_start = pos;
        let name_end = pos + colon_pos;

        // Value starts after colon, trim leading/trailing whitespace
        let raw_value = &line[colon_pos + 1..];
        let trimmed_start = raw_value.iter().position(|&b| b != b' ' && b != b'\t').unwrap_or(raw_value.len());
        let trimmed_end = raw_value.iter().rposition(|&b| b != b' ' && b != b'\t').map(|p| p + 1).unwrap_or(trimmed_start);

        let value_start = pos + colon_pos + 1 + trimmed_start;
        let value_end = pos + colon_pos + 1 + trimmed_end;

        headers.push(HeaderOffset {
            name_start,
            name_end,
            value_start,
            value_end,
        });

        pos += newline_pos + 1;
    }
}
```

```rust
#[inline]
fn bytes_eq_ignore_case(a: &[u8], b: &[u8]) -> bool {
    a.len() == b.len()
        && a.iter()
            .zip(b.iter())
            .all(|(x, y)| x.to_ascii_lowercase() == y.to_ascii_lowercase())
}

/// Find the Content-Length header value, if present.
///
/// Returns `Ok(Some(len))` if found and valid, `Ok(None)` if absent,
/// or `Err(InvalidContentLength)` if the value is non-numeric.
pub fn find_content_length(headers: &[HeaderOffset], buf: &[u8]) -> Result<Option<usize>, ParseError> {
    match header_value_for(headers, buf, b"content-length") {
        Some(value) => {
            let s = std::str::from_utf8(value).map_err(|_| ParseError::InvalidContentLength)?;
            let len = s.parse::<usize>().map_err(|_| ParseError::InvalidContentLength)?;
            Ok(Some(len))
        }
        None => Ok(None),
    }
}

/// Check if a header with the given name is present (case-insensitive).
pub fn has_header(headers: &[HeaderOffset], buf: &[u8], name: &[u8]) -> bool {
    headers.iter().any(|h| {
        bytes_eq_ignore_case(&buf[h.name_start..h.name_end], name)
    })
}

/// Get the value of a header by name (case-insensitive). Returns the first match.
pub fn header_value_for<'a>(headers: &[HeaderOffset], buf: &'a [u8], name: &[u8]) -> Option<&'a [u8]> {
    headers.iter().find_map(|h| {
        if bytes_eq_ignore_case(&buf[h.name_start..h.name_end], name) {
            Some(&buf[h.value_start..h.value_end])
        } else {
            None
        }
    })
}
```

```rust
/// Non-consuming version detection by peeking at the first request line.
///
/// Returns `None` if the buffer doesn't contain a complete request line yet.
/// Returns `Some(Ok(version))` on success.
/// Returns `Some(Err)` if the version token is unrecognized.
pub fn detect_version(buf: &[u8]) -> Option<Result<Version, ParseError>> {
    let newline_pos = memchr_newline(buf)?;

    let line_end = if newline_pos > 0 && buf[newline_pos - 1] == b'\r' {
        newline_pos - 1
    } else {
        newline_pos
    };

    let line = &buf[..line_end];

    // Look for the last space — version token follows it
    match line.iter().rposition(|&b| b == b' ') {
        Some(last_space) => {
            let token = &line[last_space + 1..];
            match token {
                b"HTTP/1.1" => Some(Ok(Version::Http11)),
                b"HTTP/1.0" => Some(Ok(Version::Http10)),
                // If it looks like an HTTP version but isn't 1.0/1.1, error
                _ if token.starts_with(b"HTTP/") => Some(Err(ParseError::UnsupportedVersion)),
                // No version token (e.g., "GET /path") — HTTP/0.9
                _ => Some(Ok(Version::Http09)),
            }
        }
        // No space at all — malformed, but let the codec handle it
        None => Some(Ok(Version::Http09)),
    }
}
```

Key: `parse_headers` returns local offsets (0-based into `header_buf`). The codec uses `header_buf` for internal lookups (`find_content_length`). When building the final `Request`, offsets are absolutized by adding `buf_offset + req_line.consumed` (for headers) and using `req_line.path_start`/`path_end` directly (already absolute from `parse_request_line`).

```rust
impl Codec for Http10Codec {
    fn decode(&mut self, buf: &[u8], buf_offset: usize) -> DecodeOutcome {
        // Parse request line (returns absolute offsets for path)
        let req_line = match parse::parse_request_line(buf, buf_offset) {
            None => {
                return DecodeOutcome {
                    result: DecodeResult::Incomplete,
                    consumed: 0,
                };
            }
            Some(Err(e)) => {
                return DecodeOutcome {
                    result: DecodeResult::Error(e),
                    consumed: 0,
                };
            }
            Some(Ok(rl)) => rl,
        };

        // Parse headers from the rest of the buffer
        // parse_headers returns local (0-based) offsets into header_buf
        let header_buf = &buf[req_line.consumed..];
        let (local_headers, header_consumed) = match parse::parse_headers(header_buf) {
            None => {
                return DecodeOutcome {
                    result: DecodeResult::Incomplete,
                    consumed: 0,
                };
            }
            Some(Err(e)) => {
                return DecodeOutcome {
                    result: DecodeResult::Error(e),
                    consumed: 0,
                };
            }
            Some(Ok(result)) => result,
        };

        let consumed = req_line.consumed + header_consumed;

        // Use local_headers + header_buf for internal lookups
        let body_framing = match parse::find_content_length(&local_headers, header_buf) {
            Ok(Some(len)) => BodyFraming::ContentLength(len),
            Ok(None) => BodyFraming::None,
            Err(e) => {
                return DecodeOutcome {
                    result: DecodeResult::Error(e),
                    consumed,
                };
            }
        };

        // Absolutize header offsets for the final Request
        let abs_offset = buf_offset + req_line.consumed;
        let headers = parse::absolutize_headers(&local_headers, abs_offset);

        DecodeOutcome {
            result: DecodeResult::Complete(Request::new(
                req_line.method,
                req_line.path_start,
                req_line.path_end,
                req_line.version,
                headers,
                body_framing,
            )),
            consumed,
        }
    }

    fn version(&self) -> Version {
        Version::Http10
    }
}
```

```rust
        // Parse headers — returns local (0-based) offsets into header_buf
        let header_buf = &buf[req_line.consumed..];
        let (local_headers, header_consumed) = match parse::parse_headers(header_buf) {
            None => {
                return DecodeOutcome {
                    result: DecodeResult::Incomplete,
                    consumed: 0,
                };
            }
            Some(Err(e)) => {
                return DecodeOutcome {
                    result: DecodeResult::Error(e),
                    consumed: 0,
                };
            }
            Some(Ok(result)) => result,
        };

        let consumed = req_line.consumed + header_consumed;

        // All header lookups use local_headers + header_buf (same coordinate space)

        // HTTP/1.1 requires Host header
        if !parse::has_header(&local_headers, header_buf, b"host") {
            return DecodeOutcome {
                result: DecodeResult::Error(ParseError::MissingHostHeader),
                consumed,
            };
        }

        // Determine body framing: chunked takes priority over Content-Length (RFC 7230 §3.3.3)
        let has_chunked = parse::header_value_for(&local_headers, header_buf, b"transfer-encoding")
            .map(|v| v.windows(7).any(|w| w.eq_ignore_ascii_case(b"chunked")))
            .unwrap_or(false);

        let body_framing = if has_chunked {
            BodyFraming::Chunked
        } else {
            match parse::find_content_length(&local_headers, header_buf) {
                Ok(Some(len)) => BodyFraming::ContentLength(len),
                Ok(None) => BodyFraming::None,
                Err(e) => {
                    return DecodeOutcome {
                        result: DecodeResult::Error(e),
                        consumed,
                    };
                }
            }
        };

        // Detect Expect: 100-continue
        let expect_continue = parse::header_value_for(&local_headers, header_buf, b"expect")
            .map(|v| v.eq_ignore_ascii_case(b"100-continue"))
            .unwrap_or(false);

        // Detect Connection header value for keep-alive decisions
        let connection_directive = parse::detect_connection_directive(&local_headers, header_buf);

        // Absolutize header offsets for the final Request
        let abs_offset = buf_offset + req_line.consumed;
        let headers = parse::absolutize_headers(&local_headers, abs_offset);

        DecodeOutcome {
            result: DecodeResult::Complete(Request::new(
                req_line.method,
                req_line.path_start,
                req_line.path_end,
                req_line.version,
                headers,
                body_framing,
            )),
            consumed,
        }
    }

    fn version(&self) -> Version {
        Version::Http11
    }
}
```

Note: `expect_continue` and `connection_directive` are detected but need to be passed through. This is addressed in Task 11 (session changes) where `Request` gains these fields.

```rust
pub(crate) struct Session {
    codec: HttpCodec,
    state: SessionState,
    /// Extracted from the last decoded request for keep-alive decisions.
    connection_directive: ConnectionDirective,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum SessionState {
    AwaitingRequest,
    RequestReady,
    ReadingBody,
    ExpectContinue,
    ResponseInProgress,
    Failed,
    Done,
    AwaitingNext,
}

impl Session {
    pub fn new(codec: HttpCodec) -> Self {
        Self {
            codec,
            state: SessionState::AwaitingRequest,
            connection_directive: ConnectionDirective::None,
        }
    }

    pub fn http09() -> Self {
        Self::new(HttpCodec::Http09(Http09Codec::new()))
    }

    pub fn detecting() -> Self {
        Self::new(HttpCodec::Detecting)
    }

    pub fn try_decode_request(
        &mut self,
        buf: &[u8],
        buf_offset: usize,
    ) -> Result<Option<(Request, usize)>, HttpError> {
        debug_assert!(
            self.state == SessionState::AwaitingRequest,
            "try_decode_request called in state {:?}",
            self.state
        );

        let outcome = self.codec.decode(buf, buf_offset);
        match outcome.result {
            DecodeResult::Complete(req) => {
                self.state = SessionState::RequestReady;
                // Store extracted directive — no buffer cloning needed
                self.connection_directive = req.connection_directive;
                Ok(Some((req, outcome.consumed)))
            }
            DecodeResult::Incomplete => Ok(None),
            DecodeResult::Error(e) => {
                self.state = SessionState::Failed;
                Err(HttpError::Parse(e))
            }
        }
    }

    pub fn begin_response(&mut self) {
        debug_assert!(
            self.state == SessionState::RequestReady
                || self.state == SessionState::ReadingBody,
            "begin_response called in state {:?}",
            self.state
        );
        self.state = SessionState::ResponseInProgress;
    }

    /// Mark that the response is finished.
    /// Returns `true` if the connection should stay alive (keep-alive).
    pub fn finish_response(&mut self) -> bool {
        debug_assert_eq!(self.state, SessionState::ResponseInProgress);

        let keep_alive = match self.codec.version() {
            Version::Http09 => false,
            Version::Http10 => {
                // HTTP/1.0: close by default, keep-alive only if requested
                self.connection_directive == ConnectionDirective::KeepAlive
            }
            Version::Http11 => {
                // HTTP/1.1: keep-alive by default, close only if requested
                self.connection_directive != ConnectionDirective::Close
            }
        };

        if keep_alive {
            self.state = SessionState::AwaitingNext;
        } else {
            self.state = SessionState::Done;
        }

        keep_alive
    }

    /// Transition from AwaitingNext to AwaitingRequest for the next request.
    pub fn prepare_next_request(&mut self) {
        debug_assert_eq!(self.state, SessionState::AwaitingNext);
        self.connection_directive = ConnectionDirective::None;
        self.state = SessionState::AwaitingRequest;
    }

    pub fn is_done(&self) -> bool {
        matches!(self.state, SessionState::Done | SessionState::Failed)
    }

    pub fn version(&self) -> Version {
        self.codec.version()
    }
}
```

```rust
    }

    // Send 100-continue if needed (lazy, on first read)
    if self.expect_continue && !self.continue_sent {
        let response = b"HTTP/1.1 100 Continue\r\n\r\n";
        self.stream.write(response).await.map_err(HttpError::Tcp)?;
        self.continue_sent = true;
    }

    match self.framing {
        BodyFraming::None => {
            self.finished = true;
            Ok(0)
        }
        BodyFraming::ContentLength(_) => self.read_content_length(dest).await,
        BodyFraming::Chunked => self.read_chunked(dest).await,
    }
}

async fn read_content_length(&mut self, dest: &mut [u8]) -> Result<usize, HttpError> {
    if self.remaining == 0 {
        self.finished = true;
        return Ok(0);
    }

    let to_read = dest.len().min(self.remaining);

    // First try to read from the existing read buffer
    let buffered = self.read_buf.unconsumed();
    if !buffered.is_empty() {
        let n = to_read.min(buffered.len());
        dest[..n].copy_from_slice(&buffered[..n]);
        self.read_buf.consume(n);
        self.remaining -= n;
        if self.remaining == 0 {
            self.finished = true;
        }
        return Ok(n);
    }

    // Read from stream
    let buf_slice = self.read_buf.writable_slice();
    let n = self.stream.read(buf_slice).await.map_err(HttpError::Tcp)?;
    if n == 0 {
        self.finished = true;
        return Err(HttpError::Closed);
    }
    self.read_buf.advance_end(n);

    // Now read from buffer
    let buffered = self.read_buf.unconsumed();
    let n = to_read.min(buffered.len());
    dest[..n].copy_from_slice(&buffered[..n]);
    self.read_buf.consume(n);
    self.remaining -= n;
    if self.remaining == 0 {
        self.finished = true;
    }
    Ok(n)
}

async fn read_chunked(&mut self, dest: &mut [u8]) -> Result<usize, HttpError> {
    loop {
        match self.chunk_state {
            ChunkState::Done => {
                self.finished = true;
                return Ok(0);
            }
            ChunkState::AwaitingSize => {
                // Read chunk size line
                let size = self.read_chunk_size().await?;
                if size == 0 {
                    self.chunk_state = ChunkState::Done;
                    self.finished = true;
                    return Ok(0);
                }
                self.chunk_state = ChunkState::ReadingData(size);
            }
            ChunkState::ReadingData(remaining) => {
                let to_read = dest.len().min(remaining);

                // Read from buffer first
                let buffered = self.read_buf.unconsumed();
                if buffered.is_empty() {
                    // Need more data from stream
                    if self.read_buf.remaining_capacity() == 0 {
                        self.read_buf.compact();
                    }
                    let buf_slice = self.read_buf.writable_slice();
                    let n = self.stream.read(buf_slice).await.map_err(HttpError::Tcp)?;
                    if n == 0 {
                        return Err(HttpError::Closed);
                    }
                    self.read_buf.advance_end(n);
                    continue;
                }

                let n = to_read.min(buffered.len());
                dest[..n].copy_from_slice(&buffered[..n]);
                self.read_buf.consume(n);

                let new_remaining = remaining - n;
                if new_remaining == 0 {
                    self.chunk_state = ChunkState::AwaitingTrailer;
                } else {
                    self.chunk_state = ChunkState::ReadingData(new_remaining);
                }
                return Ok(n);
            }
            ChunkState::AwaitingTrailer => {
                // Consume the \r\n after chunk data
                self.consume_crlf().await?;
                self.chunk_state = ChunkState::AwaitingSize;
            }
        }
    }
}

/// Read a chunk size line (hex digits followed by \r\n).
/// Handles chunk extensions (e.g., "a;ext=val\r\n") by trimming at `;`.
async fn read_chunk_size(&mut self) -> Result<usize, HttpError> {
    loop {
        let buffered = self.read_buf.unconsumed();
        if let Some(pos) = buffered.iter().position(|&b| b == b'\n') {
            let line_end = if pos > 0 && buffered[pos - 1] == b'\r' {
                pos - 1
            } else {
                pos
            };
            let line = &buffered[..line_end];
            // Trim chunk extensions at `;` (RFC 7230 Section 4.1.1)
            let hex = match line.iter().position(|&b| b == b';') {
                Some(semi) => &line[..semi],
                None => line,
            };
            let size = usize::from_str_radix(
                std::str::from_utf8(hex).map_err(|_| {
                    HttpError::Parse(crate::net::http::error::ParseError::InvalidChunkEncoding)
                })?,
                16,
            )
            .map_err(|_| {
                HttpError::Parse(crate::net::http::error::ParseError::InvalidChunkEncoding)
            })?;
            self.read_buf.consume(pos + 1);
            return Ok(size);
        }

        // Need more data
        if self.read_buf.remaining_capacity() == 0 {
            self.read_buf.compact();
        }
        let buf_slice = self.read_buf.writable_slice();
        let n = self.stream.read(buf_slice).await.map_err(HttpError::Tcp)?;
        if n == 0 {
            return Err(HttpError::Closed);
        }
        self.read_buf.advance_end(n);
    }
}

/// Consume \r\n from the buffer.
async fn consume_crlf(&mut self) -> Result<(), HttpError> {
    loop {
        let buffered = self.read_buf.unconsumed();
        if buffered.len() >= 2 {
            // Expect \r\n
            if buffered[0] == b'\r' && buffered[1] == b'\n' {
                self.read_buf.consume(2);
            } else if buffered[0] == b'\n' {
                self.read_buf.consume(1);
            }
            return Ok(());
        }
        if buffered.len() == 1 && buffered[0] == b'\n' {
            self.read_buf.consume(1);
            return Ok(());
        }

        // Need more data
        if self.read_buf.remaining_capacity() == 0 {
            self.read_buf.compact();
        }
        let buf_slice = self.read_buf.writable_slice();
        let n = self.stream.read(buf_slice).await.map_err(HttpError::Tcp)?;
        if n == 0 {
            return Err(HttpError::Closed);
        }
        self.read_buf.advance_end(n);
    }
}
```

```rust
use crate::net::http::{HttpError, buffer::WriteBuffer, request::Version, session::Session};
use crate::net::socket::TcpStream;

/// Response state machine.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum ResponseState {
    /// Status and headers not yet sent.
    Headers,
    /// Headers flushed, writing body.
    Body,
    /// Response complete.
    Finished,
}

/// Writes HTTP response data to the client.
pub struct ResponseWriter<'conn> {
    write_buf: &'conn mut WriteBuffer,
    stream: &'conn TcpStream,
    session: &'conn mut Session,
    finished: bool,
    version: Version,
    state: ResponseState,
    status_code: u16,
    status_reason: String,
    response_headers: Vec<(String, String)>,
    is_head: bool,
    chunked: bool,
}

impl<'conn> ResponseWriter<'conn> {
    pub(crate) fn new(
        write_buf: &'conn mut WriteBuffer,
        stream: &'conn TcpStream,
        session: &'conn mut Session,
        version: Version,
        is_head: bool,
    ) -> Self {
        session.begin_response();
        Self {
            write_buf,
            stream,
            session,
            finished: false,
            version,
            state: ResponseState::Headers,
            status_code: 200,
            status_reason: String::from("OK"),
            response_headers: Vec::new(),
            is_head,
            chunked: false,
        }
    }

    /// Set the response status code and reason phrase.
    /// Defaults to 200 OK if not called.
    /// No-op for HTTP/0.9.
    pub fn set_status(&mut self, code: u16, reason: &str) {
        if self.version == Version::Http09 {
            return;
        }
        self.status_code = code;
        self.status_reason = reason.to_string();
    }

    /// Add a response header. Can be called multiple times.
    /// No-op for HTTP/0.9.
    pub fn add_header(&mut self, name: &str, value: &str) {
        if self.version == Version::Http09 {
            return;
        }
        self.response_headers.push((name.to_string(), value.to_string()));
    }

    /// Write body bytes to the response.
    ///
    /// On first call for HTTP/1.x, flushes the status line and headers.
    /// For HEAD requests, body bytes are suppressed but headers are still sent.
    pub async fn write_body(&mut self, data: &[u8]) -> Result<usize, HttpError> {
        if self.state == ResponseState::Headers && self.version != Version::Http09 {
            self.flush_headers().await?;
        }

        // HEAD responses: suppress body but still "write" for Content-Length accounting
        if self.is_head {
            return Ok(data.len());
        }

        if self.chunked {
            // Write chunk header: hex size + \r\n
            let chunk_header = format!("{:x}\r\n", data.len());
            self.write_all(chunk_header.as_bytes()).await?;
            self.write_all(data).await?;
            self.write_all(b"\r\n").await?;
            Ok(data.len())
        } else {
            self.write_all(data).await
        }
    }

    /// Signal that the response is complete. Flushes any remaining buffered data.
    pub async fn finish(mut self) -> Result<(), HttpError> {
        if self.state == ResponseState::Headers && self.version != Version::Http09 {
            // Headers-only response (e.g., 204, 304)
            // Add Content-Length: 0 if not already set
            if !self.response_headers.iter().any(|(n, _)| n.eq_ignore_ascii_case("content-length")) {
                self.response_headers.push(("Content-Length".to_string(), "0".to_string()));
            }
            self.flush_headers().await?;
        }

        if self.chunked {
            // Send final chunk: 0\r\n\r\n
            self.write_all(b"0\r\n\r\n").await?;
        }

        self.flush().await?;
        self.session.finish_response();
        self.finished = true;
        Ok(())
    }

    /// Flush headers to the wire. Called once on first write_body or finish.
    async fn flush_headers(&mut self) -> Result<(), HttpError> {
        debug_assert_eq!(self.state, ResponseState::Headers);

        let status_line = format_status_line(self.status_code, &self.status_reason, self.version);
        self.write_all(status_line.as_bytes()).await?;

        // Check if handler set Content-Length
        let has_content_length = self.response_headers.iter().any(|(n, _)| n.eq_ignore_ascii_case("content-length"));

        // If no Content-Length, decide on chunked
        if !has_content_length && self.version == Version::Http11 {
            self.chunked = true;
            self.response_headers.push(("Transfer-Encoding".to_string(), "chunked".to_string()));
        }

        for (name, value) in &self.response_headers {
            let header = format_header(name, value);
            self.write_all(header.as_bytes()).await?;
        }

        // End of headers
        self.write_all(b"\r\n").await?;
        self.state = ResponseState::Body;
        Ok(())
    }

    /// Write all bytes to the write buffer, flushing as needed.
    async fn write_all(&mut self, data: &[u8]) -> Result<usize, HttpError> {
        let mut total_written = 0;
        while total_written < data.len() {
            let n = self.write_buf.write(&data[total_written..]);
            total_written += n;

            if self.write_buf.remaining_capacity() == 0 || total_written == data.len() {
                self.flush().await?;
            }
        }
        Ok(total_written)
    }

    /// Flush the write buffer to the TcpStream.
    async fn flush(&mut self) -> Result<(), HttpError> {
        while !self.write_buf.is_empty() {
            let pending = self.write_buf.pending();
            let n = self.stream.write(pending).await.map_err(HttpError::Tcp)?;
            self.write_buf.advance(n);
        }
        Ok(())
    }
}

impl Drop for ResponseWriter<'_> {
    fn drop(&mut self) {
        if !self.finished {
            self.session.finish_response();
        }
    }
}

fn format_status_line(code: u16, reason: &str, version: Version) -> String {
    format!("{} {} {}\r\n", version, code, reason)
}

fn format_header(name: &str, value: &str) -> String {
    format!("{}: {}\r\n", name, value)
}
```
